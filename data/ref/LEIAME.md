# Dados de referência (reais)

`municipios_ibge.csv`: código IBGE, nome, latitude e longitude de cada município brasileiro.
Fonte: https://github.com/kelvins/municipios-brasileiros (baseado em dados do IBGE).

Usados só para a geografia: coordenadas das cidades de destino e dos CDs, e distâncias.
Os pedidos, transportadoras e prazos do projeto continuam sendo os dados **fictícios** do desafio.
